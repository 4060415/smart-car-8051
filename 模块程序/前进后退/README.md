# 前进 / 后退 最简演示程序

`fwd_back.c` —— 上电就跑，不需要遥控器、不需要传感器、不需要按键。

```
前进 2 秒 -> 停车 0.5 秒 -> 后退 2 秒 -> 停车 0.5 秒 -> 再前进 ……（一直循环）
```

## 代码怎么讲（对着代码看就行）

整个程序只有三个电机指令，`P0` 全字节写出去：

| 动作 | P0 值 | 含义 |
|---|---|---|
| 前进 | `0xF5` | `0x80`(P0.7 恒 1) + `0x05`(IN1+IN3) + `0x10`(左轮使能) + `0x20`(右轮使能) + `0x40`(蜂鸣器静音) |
| 后退 | `0xFA` | 同上，只把方向位换成 `0x0A`（IN2+IN4） |
| 停车 | `0xC0` | 四个方向位全 0，两个使能也拉低 |

主循环就是「写一次 P0 → 延时 → 再写一次」，一行一个动作。

引脚依据是 `firmware/car/config.h`（本工程唯一需要现场核对的引脚文件）：
`P0.0~P0.3 = IN1~IN4`、`P0.4 = ENA`、`P0.5 = ENB`、`P0.6 = 蜂鸣器（1 = 静音）`。

## 已验证的部分 / 未验证的部分

- **已验证**：编译 0 错 0 警告；`delay_ms` 的循环常数是对着编译出来的汇编数周期校正的
  （内层 `j < 96` 编成 `INC` + `CJNE` 共 3 个机器周期，一整轮 924 个机器周期
  = 924 × 1.085 µs ≈ 1 ms，所以 `delay_ms(2000)` 约 2.0 秒）。
- **未验证**：还没上机跑过。上机时只看两点 —— ① 车确实前进、确实后退；
  ② 前进和后退各约 2 秒。

## 两个小提示

1. **如果方向反了**（写前进结果车往后走）：把 `fwd_back.c` 里
   `M_FORWARD` 和 `M_BACK` 两个宏的值对调，重新编译即可，不用改接线。
2. **如果车速太快**：本程序不做 PWM，两个轮子都是全速（占空比 100%）。
   先把 `RUN_MS` 改小（比如 1000）缩短演示距离；确实需要慢速再考虑加 PWM ——
   现成的实现（100 Hz、档位 40/55/70/85/100%）在 `firmware/c51/main.c` 的
   Timer0 中断里，本演示程序刻意不引入中断，保持最简单。
