## 2. 完整引脚表（核心，直接抄）

> 段序、极性都已实测核对。**照抄即可**，别按"通用教程"的 51 小车引脚写——本板很多脚与通用例程是反的。

### P0 口（开漏，板上每脚挂 10K 排阻上拉）—— 输出

| 引脚 | 功能 | 电平逻辑 |
|---|---|---|
| `P0.0` | L293D `INPUT1`（电机方向） | 见 §3 电机图案 |
| `P0.1` | L293D `INPUT2` | ↑ |
| `P0.2` | L293D `INPUT3` | ↑ |
| `P0.3` | L293D `INPUT4` | ↑ |
| `P0.4` | `ENA`（电机使能） | **高 = 使能**，可 PWM 调速 |
| `P0.5` | `ENB`（电机使能） | **高 = 使能**，可 PWM 调速 |
| `P0.6` | 蜂鸣器（S8550 PNP 驱动） | **低 = 发声**；无源，必须给方波 |
| `P0.7` | 未使用（只有排阻上拉） | 写 1 |

### P1 口

| 引脚 | 功能 | 电平逻辑 |
|---|---|---|
| `P1.0` | **右光敏**（LM393 比较器 OUTB） | **见光 = 低(0)，遮住 = 高(1)** |
| `P1.1` | **左光敏**（LM393 比较器 OUTA） | 同上 |
| `P1.2` | **超声波 Echo**（回波输入） | 高电平宽度 ∝ 距离 |
| `P1.3` | **超声波 Trig**（触发输出） | 高脉冲 ≥10 µs |
| `P1.4` / `P1.5` | 2 脚接插件（各带 4.7K 上拉，疑 I²C） | 用途未定，先不用 |
| `P1.6` | 网标号 `P16`（接插件） | 用途未定 |
| `P1.7` | 图上无连线 | 未使用 |

### P2 口 —— 数码管 + 指示灯

| 引脚 | 功能 | 电平逻辑 |
|---|---|---|
| `P2.7` | 数码管 **a** | **共阳：写 0 点亮** |
| `P2.6` | 数码管 **b** | ↑ |
| `P2.5` | 数码管 **c** | ↑ |
| `P2.4` | 数码管 **d** | ↑ |
| `P2.3` | 数码管 **e** | ↑ |
| `P2.2` | 数码管 **f** | ↑ |
| `P2.1` | 数码管 **g** | ↑ |
| `P2.0` | **D3 指示灯**（不是段选！） | 写 0 亮 |

> ⚠️ **段序是反的**：`a` 在最高位 `P2.7`，`g` 在最低位 `P2.1`；**`P2.0` 不是段选**（它接 D3 灯）。按 `P2.0=a … P2.6=g` 写会整片错位一位。

### P3 口 —— 输入为主

| 引脚 | 功能 | 电平逻辑 |
|---|---|---|
| `P3.0` | `RXD`（下载/串口，CH340） | 固定，别占用 |
| `P3.1` | `TXD`（下载/串口） | 固定，别占用 |
| `P3.2` | **按键 S4**（10K 上拉） | **按下 = 低(0)** |
| `P3.3` | **红外接收头 0038 输出**（INT1，第 13 脚） | 空闲高；收到 38 kHz 载波为低 |
| `P3.4` | **按键 S3**（10K 上拉） | **按下 = 低(0)** |
| `P3.5` | **循迹左探头**（V2） | **白底（有反射）= 低(0)；压黑线 = 高(1)** |
| `P3.6` | **循迹右探头**（V3） | 同上 |
| `P3.7` | **车头红外近距避障**（V7/V4 对管） | 量程只有 1~2 cm；极性上电自校准 |

> ⚠️ 三个最常被"通用教程"带偏的脚：
> 1. **红外接收头接 `P3.3`（INT1），不是 `P3.2`** —— `P3.2` 是按键 S4。
> 2. **光敏在 `P1.0`/`P1.1`**（`P1.0` 右、`P1.1` 左），不是常见的"P1 口其他位"。
> 3. **`P3.7` 是车头红外避障对管**（V7/V4），不是循迹接插件；量程极近（1~2 cm），只能当"最后一道兜底"，不能替代超声波。

## 3. 电机驱动：P0 输出图案

`b0..b3 = IN1..IN4`，`b4 = ENA`，`b5 = ENB`，`b6 = 蜂鸣器(1=静音)`，`b7 = 1`

| 动作 | P0 图案（汇编版直接驱动参考） | 低 4 位方向位 |
|---|---|---|
| 停止 | `0C0H` | `00H`（ENA/ENB 一起拉低） |
| 前进 | `0F5H` | `05H`（IN1+IN3） |
| 后退 | `0FAH` | `0AH`（IN2+IN4） |
| 左转（原地） | `0F6H` | `06H`（IN2+IN3） |
| 右转（原地） | `0F9H` | `09H`（IN1+IN4） |

> - `ENA`/`ENB` **是 MCU 驱动的**（不是跳线接 VCC）→ **必须显式拉高电机才会转**。
> - **哪个轮子是左、哪个是右**：图纸只给位号 M1/M2，没标左右。若实测相反，对调电机的两根方向线，或在代码里加 `LEFT_REVERSE`/`RIGHT_REVERSE` 开关。
> - C 版固件走 `motor_set()` + 软件 PWM，主循环**不要直接写 P0**（否则和中断里组装 P0 打架，电机乱抽）。

## 4. 传感器极性速查（写判断直接抄）

| 传感器 | 条件 → 电平 |
|---|---|
| 光敏（`P1.1` 左 / `P1.0` 右） | **见光 → 低(0)**；遮住 → 高(1) |
| 循迹探头（`P3.5` 左 / `P3.6` 右） | **白底（有反射）→ 低(0)**；**压到黑线 → 高(1)** |
| 按键 `S3` / `S4` | **按下 → 低(0)** |
| 红外接收头 0038 | 空闲高；收到载波变低（NEC 解调出反向基带脉冲） |
| 车头避障对管 `P3.7` | 量程 1~2 cm；极性由固件**上电时读一次做基准**（自校准），别写死 |

> ⚠️ **名字陷阱**：循迹探头"有反射=低"，所以**"压到黑线"读到的是 `1`（高）**。判断"压线"用 `== 1`，不是 `== 0`。
> - 左探头压黑线 → 车偏线右侧 → 往**左**修；右探头压黑线 → 往右修。
> - 两个都 0 = 线在正中（直行）；两个都 1 = 大面积黑/脱线（停车或按上次方向找线）。
> - 只有两个探头时**分不清"线在正中"和"完全脱线"**（都是 `00`）→ 必须加超时保护。

## 5. 数码管 / 蜂鸣器

### 段码（含 D3 灭，直接 `MOV P2, A`）

```
bit7..bit1 = a b c d e f g（1 = 灭），bit0 = D3（1 = 灭）
0 = 03H   1 = 9FH   2 = 25H   3 = 0DH   4 = 99H
5 = 49H   6 = 41H   7 = 1FH   8 = 01H   9 = 09H
```

### 蜂鸣器

- **无源 + PNP（S8550）**：**不给方波就不响**（只给高低电平只有"哒"一声）。
- 省事做法：在定时器中断里每几个 tick 翻一次 `P0.6`（例：100 µs tick 每 5 次翻一次 ≈ 1 kHz），主循环零负担。

## 6. 遥控器键值（NEC `cmd` 字节）

> 已上机确认。完整 21 码表见 `docs\遥控器码值表.md`。

| 功能 | 键值 | 按键 |
|---|---|---|
| 前进 | `0x46` | CH |
| 后退 | `0x15` | − |
| 左转 | `0x44` | \|<< |
| 右转 | `0x43` | >>\| |
| 暂停/停止 | `0x40` | + |
| 加速 | `0x5A` | 数字 6 |
| 减速 | `0x08` | 数字 4 |
| 切模式 | `0x1C` | 数字 5 |
| 录制 | `0x42` | 数字 7 |
| 回放 | `0x52` | 数字 8 |
| 清空记录 | `0x4A` | 数字 9 |

> NEC 帧 = 引导码 + 地址 + ~地址 + 命令 + ~命令（后两字节互补可自检）。按住不放发**重复帧**；有些遥控器**不发重复帧** → 想"按住=持续动作"必须自己加"超时即松手"判定。

## 7. 定时器 / 存储 / 关键参数

### 定时器（写代码前先抄）

| 资源 | 配置 | 用途 |
|---|---|---|
| **Timer0** | 方式 2，`TH0=TL0=164` → 92 机器周期 ≈ **99.8 µs** | 100 µs 硬件时基；10 ms 节拍 = 计 100 次 |
| **Timer1** | 方式 2，`TH1=TL1=0xFD`，`SMOD=0` | 串口 9600 波特率（占用它 = 放弃串口） |
| `TMOD` | `22H`（T1 方式2 + T0 方式2） | 共用寄存器，改 T0 别带歪串口 |

### 存储布局

| 区域 | 容量 | 说明 |
|---|---:|---|
| Flash | 8 KB | Eval 编译器限 **2048 B `code`**（只算 code，大数组放 RAM 不吃额度） |
| `DATA` | 80 B（`30H`~`7F`） | 全局变量 |
| 位寻址区 | `20H`~`2F`（16 B） | 可放 128 个位变量 |
| `IDATA` | 128 B（`80H`~`FFH`） | `@R0`/`@R1` 访问 |
| 片内扩展 RAM | 256 B | 大数组/缓冲用 `MOVX @DPTR` |

## 8. 供电与下载（阶段 0 必须知道，否则白干）

### 供电

- **USB 供电最安全**：CH340 给 5V、限流，首选首测环境。
- 电池盒 4×1.5 V，开关 `S1`。⚠️ **新碱性电池空载 6.0~6.4 V，超过 MCU 5.5 V 上限**（板上无稳压）→ 用 **4 节镍氢（4.8 V）** 或串一只二极管降 0.7 V。
- 换电脑后 **COM 号会变**，每次在设备管理器里认"CH340"那个口。

### 下载（STC-ISP）

```
① 型号选 STC89C52RC
② 串口选 COM7（⚠️ COM3~6 是蓝牙虚拟串口，别选）
③ 打开 .hex → 点【下载/编程】→ ④ 然后才冷启动
```

- **冷启动是必须的**：点完下载后再拨 `S1` 关→等 1~2 秒→开（或拔插一次 USB）。
- 串口 **9600 8N1**；同一时刻串口只能被一个程序占用（下载软件和串口助手互斥）。

## 9. 电气约束与踩坑速查（同学最容易踩的）

| # | 坑 | 对策 |
|---|---|---|
| 1 | **`P0` 是开漏口**：写 1 只是"放开"，靠 10K 排阻上拉，上升沿偏慢 | 只做低速开关和低频 PWM（500 Hz 量级）；高速别用 P0 |
| 2 | **`P2` 整口被数码管占用** | 用片内扩展 RAM 只能 `MOVX @DPTR`；`MOVX @Ri` 会拿 P2 当高 8 位地址，把显示打花 |
| 3 | **超声波插座线序与模块脚序相反** | 模块脚序常为 `VCC/Trig/Echo/GND`，板上可能是 `GND/Echo/Trig/VCC` —— **不能直插**，按丝印一根根接；接反会发热 |
| 4 | **遥控 + 串口打印冲突** | 9600 下打一行 40 字符要 42 ms，一帧 NEC 才 67 ms → 打印"噎住"红外，所有键解出同一个值。**正式跑遥控时关掉调试打印** |
| 5 | 蜂鸣器只"哒"一声 | 无源，必须给方波 |
| 6 | 按键一次触发多次 | 必须去抖（10~20 ms）+ "松手才认下一次" |
| 7 | 一带电机就复位重启 | 电池带载压降大（电量不足），换电池 |
| 8 | 编译通过就以为功能对 | 编译器和硬件是两回事 → **上板子实测**；跑电机前先把轮子架空 |

## 10. 如果板子不是同一批：快速自证引脚（2 分钟）

烧探测程序 `probe.hex` / `probe2.hex`（源码在 `firmware/probe/`，或直接用已生成的 `.hex`）：

1. 先把要观察的端口**全部写 1**（放开成输入），其它口保持安全（电机输出写"停"图案）；
2. 主循环逐位读、和上一轮比，**哪位变了就显示哪位**（数码管显脚号、D3 显高低，不用串口）；
3. 用手电照/遮光敏、白纸黑胶带过探头、按按键，就能一次问出"哪只脚 + 什么极性"。

> 本项目的光敏 `P1.1`/`P1.0`、探头 `P3.5`/`P3.6` 极性、车头对管 `P3.7` 脚位，就是这么在实物上测出来的。
