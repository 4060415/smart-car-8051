## 1. 一句话结构

避障**不是一个模式**，而是两层：

```
主循环 ② (L2783) ──> av_gate()          【判定层】每趟主循环跑一次，只更新 avst 状态
                          │
                          └─> motor_set() ──> motor_set_core() (L817-834)  【执行层】
                                             按 avst 改写动作 / 强制刹停 —— 唯一出口

注：普通版 `motor_set()` 是**宏**（L909，直接展开成 `motor_set_core`），
    只有 `-Debug` 变体才多包一层打印 `ms_dbg()`（L883–910）。`apply_gear` 同理（L971–979）。
```

- **判定层**：`av_gate()` 决定 `avst`（放行 / 弧线 / 原地转 / 刹停锁存 / 人已接管）。
- **执行层**：所有电机动作都经过 `motor_set_core()`，避障在那里改写动作或刹停。
  ⇒ 这就是「有障碍时遥控照样能响铃、换显示、录制，只是车最后一步出不去」的原因。

| 行号 | 段 | 条件 → 行为 |

## 3. 分档真值表与门限

状态码（L206–210）：

| 值 | 名字 | 含义 | 执行层行为 |
|---|---|---|---|
| 0 | `AV_FREE` | 放行 | 按原动作走 |
| 1 | `AV_TURN` | 近区 | 动作一律改写成**原地右转** |
| 2 | `AV_HOLD` | 太近 | **刹停 + 锁存**，等遥控接管 |
| 3 | `AV_HUMAN` | 人已接管 | 完全放行 |
| 4 | `AV_ARC` | 中区（C17 新增） | 改写成**弧线右绕**，车不停 |

距离门限（L213–216，单位 tick，1 tick ≈ 100 µs ≈ 1.7 cm）：

| 常量 | 值 | 换算 | 含义 |
|---|---|---|---|
| `US_NEAR` | 12 | ≈ 21 cm | 更近 → 参与避让 |
| `US_CLEAR` | 7 | ≈ 12 cm | 退到这儿才算"让开"（滞回，防抖） |
| `AV_SPIN` | 7 | ≈ 12 cm | 比这更近 → 从弧线降级为原地右转 |
| `US_STOP` | 3 | ≈ 5 cm | 更近 → 刹停锁存 |

时间门限（L147–161）：

| 常量 | 值 | 换算 | 含义 |
|---|---|---|---|
| `AV_DEC_TICKS` | 2800 | ≈ 280 ms | 一次避让决定的保持时间（C17） |
| `AVBEEP_TICKS` | 6912 | ≈ 0.69 s | 锁存期间间歇提醒间隔 |
| `AVBEEP_N` | 3 | — | 一次遇障共响几声（含刹停那声）后安静，车仍停着 |
| `AV_CLEAR_TICKS` | 5000 | ≈ 0.5 s | 障碍要持续退远这么久才算真让开 |
| `IR_BEEP_SILENT` | 1 | — | 车头红外那路**静音**（刹车功能保留） |

功能开关（可用编译命令行覆盖，`#ifndef` 包着）：

| 开关 | 行号 | 当前值 | 作用 |
|---|---|---|---|
| `AV_L1` | 88–90 | **1** | 1 = C17 分级 + 决策保持；**0 = 退回 C16 行为，应得到逐字节相同的旧 hex**（回退点） |
| `AV_SCOPE` | 70–72 | 0 | 超声波自测变体：只反复跑 `us_read()` 并显示到数码管，用来分清"测距不行"还是"避障没用上" |

### 7.2 实机行为

- [ ] 手动模式：≥21 cm 直行不受影响；12~21 cm 弧线右绕（**不停车**）；5~12 cm 原地右转
- [ ] <5 cm：刹停 + 数码管/蜂鸣提示，**锁存**（障碍自己挪开车也不走），按遥控任意键才解除
- [ ] 锁存期间按板上 S3 加档：**车不会开起来**（L949）
- [ ] 决策保持：一次避让决定维持约 280 ms 不来回抖动
- [ ] 车头红外贴着（1~2 cm）：**三种模式都立即刹车**，且这个刹车**关不掉**
- [ ] 循迹模式：超声波**不参与**（不会被推离黑线），红外刹车**仍然生效**
- [ ] 倒车：超声波不参与（不会倒着倒着原地打转），限速/限时兜底照常
- [ ] 录制中：超声波不参与（`D3` 灭），但**车头红外照样刹**
- [ ] 回放中：不走避障，遇障**停车不绕行**；退出回放后避障重新武装
- [ ] 遥控数字键 5 / 板上 S4 长按：都能开关超声波避障（开=两声，关=一声长音）
- [ ] 超声波关掉后，近距提示音（"倒车雷达"）按避障门限响起

## 10. 附录：当前工作树的「未提交」改动（与验收相关）

`git diff HEAD -- firmware/c51/main.c` = **+102 / −32 行**（2026-09-22 那轮，日期见源码注释）。
`git status` 里 `main.c`、三个 hex、`main_abs.asm`、`main.SRC` 都是 `M`。

| 类别 | 改动 | 对验收的影响 |
|---|---|---|
| ★ **避障** | `av_gate()` 锁存分支里**新增「循迹自动解锁」**（**L1442–1445**）：`mode == MODE_TRACK` → `AV_FREE` + return。C17 里该处是 `if (avoid_off() \|\| mode == MODE_TRACK) return;`，**循迹一旦被车头红外误触发就永久钉死** | 这是工作树相对 C17 的**唯一避障逻辑改动**；验收时对应 §8 第 1 条与 §7.2 的循迹项 |
| 循迹 | 删掉 `TRK_TMO_TICKS` / `last_line`，重写 `track_step()`（L1170 起）：两个探头都不压线 → **一直直走找线，不再 0.5 s 停车**（对齐参考工程 `巡线ok` 的 `Line_Task()`） | 循迹不再"跑一段就停"；与避障无耦合，但同一轮改动 |
| 速度 | `duty_tab` 由 `{4,8,12,16,20}` 改为 **`{8,11,14,17,20}`**（40/55/70/85/100%），去掉 20% 那一档（L310 起） | **避障绕行的实车速度变了**：弧线 / 原地转都更快；`arc_tab` 未改，但占外轮比例变小 ⇒ 弯更急 |
| 结构 | `motor_set`→`motor_set_core`、`apply_gear`→`apply_gear_core`，各加一层只在 `-Debug` 编入的 `ms_dbg()` 打印包装（**L883–910 / L971–979**） | 普通版是宏，**执行层唯一出口仍是 `motor_set_core()`**；`-Debug` 版多打 `! MS act= dir= A= B=` 行（判读单轮 / 两轮同速就靠它） |
