## 3. 这次被实物"盖章"的图纸结论

`docs\引脚表_原理图追线.md` 里那些从 PDF 矢量数据推出来的脚位，**现在是实测确认过的**：

| 结论 | 状态 |
|---|---|
| 电机 `P0.0`~`P0.3` = L293D `INPUT1~4`；`P0.4`/`P0.5` = `ENA`/`ENB`（由 MCU 驱动） | ✅ 实物一致 |
| 蜂鸣器 = `P0.6`（S8550 PNP，**低电平发声**） | ✅ |
| 数码管段序 `a=P2.7 … g=P2.1`，**`P2.0` 不是段选**（`P2.0`→R10→D3 指示灯） | ✅ |
| 红外 0038 = **`P3.3`（INT1 / 第 13 脚）**，不是 `P3.2` | ✅ |
| 按键 `S4=P3.2`、`S3=P3.4` | ✅ |
| 循迹探头 `V2=P3.5`、`V3=P3.6`（节点低 = 触发） | ✅ |
| **循迹探头的黑/白极性** | ✅ **2026-09-18 实测**：白纸（有反射）= 低，黑物（无反射）= 高 → **压黑线读到 1**；且 D3 灭 = **电平稳定**（原担心的"未经比较器整形会停在中间值"**排除**） |
| **寻光 `P1.1`（左光敏）、`P1.0`（右光敏）** | ✅ **2026-09-18 实测**（盖住左/右光敏看数码管跳哪只脚） |
| ⚠️ `P1.0` 原本被判"图上无连线、未使用" | ❌ **实测推翻**：它是寻光第二路。**"没找到 ≠ 证明没有"再次应验** |
| **超声波：Echo = `P1.2`（网标号 `P12EC`）、Trig = `P1.3`（网标号 `P13TR`）** | ✅ |

**意义**：这套"PDF 里标号是真文字 + 导线是精确线段 + 结点圆点判连接"的追线方法，
在实物上被验证有效。报告里"软件设计依据 / 引脚分配"那一节可以据此写，
并且可以正面回答"你怎么确定引脚是对的"这个答辩问题 —— 两条独立证据：
**图纸矢量追线** + **probe2 逐脚实物复核**。
