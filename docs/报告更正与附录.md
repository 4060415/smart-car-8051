## 1.1 §1.3 系统组成与工作原理（第二段）

**【原文】**

> 工作时，操作者通过红外遥控器发射 38 kHz 载波指令，0038 一体化接收头完成接收与解调，单片机经外部中断按遥控协议解码出功能键值；循迹、避障、寻光等传感信号经 LM393 比较器整形后以开关量送入单片机 I/O 口。

**【改为】**

> 工作时，操作者通过红外遥控器发射 38 kHz 载波指令，0038 一体化接收头完成接收与解调，其输出接单片机 **P3.3（INT1 / 第 13 脚）**；程序以定时器产生的 **100 μs 硬件时基**在电平跳变处测量脉宽，按 NEC 协议（引导码 + 32 位数据 + 互补校验 + 重复帧）解出功能键值，每个动作单元只保留"运动方式 + 持续时间"。循迹与避障共用两路**红外反射式探头**，输出直接接 **P3.5、P3.6**，**有反射（白底）时节点为低电平、无反射（黑线或前方无遮挡）时为高电平**（实测：白纸读到 `0`、黑色物体读到 `1`，且电平稳定）；寻光由两只 **5528 光敏电阻**经 **LM393 比较器**整形为开关量，两路输出分别接 **`P1.1`（左光敏）与 `P1.0`（右光敏）**（均已实物验证），向单片机提供"两侧光照强弱"的比较依据。

## 1.7 §4.3 资源规划与可靠性设计 —— 整节替换建议

**【原文】**

> （1）定时资源：Timer0 提供 10 ms 统一节拍，供回放调度、录制计时与按键长按检测使用；红外解码使用外部中断捕获脉冲边沿，二者互不阻塞。

**【改为】**

> （1）定时资源：**Timer0 工作于方式 2（8 位自动重装，重装值 164，约 100 μs）**，在中断中维护一个 16 位时基计数器；**10 ms 节拍由计满 100 次时基得到**，供回放调度、录制计时与松键超时检测使用。**红外解码不使用外部中断**，而是在主循环中轮询 `P3.3` 的电平跳变、并用同一 100 μs 时基测量脉宽（该方案已在实物上验证）；这样红外接收、按键扫描、数码管刷新与回放调度互不阻塞，也不需要关闭中断。**Timer1 工作于方式 2（`TH1`=0FDH、`SMOD`=0），作为串口 9600 bit/s 的波特率发生器**，仅用于调试输出，不参与节拍与 PWM。PWM 调速由 Timer0 的 100 μs 中断在软件中生成，占空比以 8~16 级量化。

**【（2）存储规划 —— 原文补全为】**

> （2）存储规划：动作缓冲区 **240 B（80 单元）**，按"动作码 1 B + 时长低字节 1 B + 时长高字节 1 B"存放，时间单位为 10 ms。缓冲区置于**片内扩展 RAM**（STC89C52RC 共 512 B RAM = 256 B 标准 + 256 B 片内扩展），通过 `MOVX @DPTR` 间接访问（**不使用 `MOVX @Ri`**：该寻址方式以 `P2` 口作为高 8 位地址，而 `P2` 整口用于数码管段选与指示灯，会造成显示错乱）。运行变量（有效记录数、当前索引、当前动作累计时长、当前动作码）使用少量直接寻址字节，在状态切换时复位。

**【（3）容错与安全 —— 末尾补一条】**

> 回放前检查有效记录数，空记录拒绝回放并提示；录制缓冲区满立即封存并提示；回放中任意遥控键立即中断回放；**回放过程中若前方检测到障碍，立即中断回放并停车**（防止自动执行段撞击障碍）；上电初始化先关闭电机使能，防止误动作。

# 七、附录 C：动作缓冲区数据格式（建议稿，供报告"存储规划"一节使用）

**缓冲区结构（建议）**

```
片内扩展 RAM（实测确认可读写，见 docs\阶段0实测指南.md 第四节），
起始地址 BUF_BASE，共 240 B；**只能用 DPTR 访问**（MOVX @Ri 会用到 P2，
而 P2 整口是数码管段选，会把显示打花）

单元 i（i = 0 … N−1）：
  偏移 i*3 + 0 ：动作码   1 B
  偏移 i*3 + 1 ：时长低字节 1 B
  偏移 i*3 + 2 ：时长高字节 1 B
  时长 = (高字节 << 8) | 低字节 ，单位 10 ms
```

**动作码定义（与报告表 4 一致）**

| 动作码 | 含义 | L293D 输出效果 | 时间单位 |
|---|---|---|---|
| `0x00` | 停止 | `ENA`/`ENB` 拉低，两路断电 | 10 ms |
| `0x01` | 前进 | 左右电机同向正转 | 10 ms |
| `0x02` | 后退 | 左右电机同向反转 | 10 ms |
| `0x03` | 左转 | M1 反转 + M2 正转（原地） | 10 ms |
| `0x04` | 右转 | M1 正转 + M2 反转（原地） | 10 ms |

**管理规则（建议）**

| 规则 | 判据 |
|---|---|
| 有效记录数 | 独立变量 `REC_N`（1 B，取值 0~80），**不占用缓冲区**，可省去结束标记 |
| 空记录 | `REC_N == 0` → 拒绝回放，蜂鸣器短鸣 + 数码管显示错误标识 |
| 判满 | `REC_N >= 80` → 封存当前动作、停止录制、停车并提示 |
| 同动作合并 | 新动作码 == 当前动作码 → **只累加时长**（上限 65535，溢出则封存并新建单元），不新增单元 |
| 溢出保护 | 写入前一律先判 `REC_N < 80`，**任何写入路径都不得越过缓冲区末尾** |
| 回放结束 | 索引 `i == REC_N` → 停车、返回手动模式 |

> 若后续扩展 24C02 EEPROM 掉电保存，建议在上述 240 B 之前增加
> `记录头（1 B 版本号 + 1 B 记录数 + 1 B 校验和）`，上电校验通过后才允许回放。

## 9.1 五处**必须改**的（与报告描述直接冲突）

| # | 报告/旧文档可能写着的 | ★ 改成（可直接粘贴） |
|---|---|---|
| 1 | 指示灯 `D3` 用于指示"**电机在动**" | **指示灯 `D3`（`P2.0`，写 0 亮）在最终固件中用作「超声波避障开关状态」指示：亮 = 避障参与，灭 = 避障关闭（录制期间必灭）。**<br>⚠️ 汇编版仍是"亮 = 电机在动"，**两版语义不同，引用前先看版本**。 |

## 9.3 一条**应当如实写**的（比"稳定可靠"更经得起问）
