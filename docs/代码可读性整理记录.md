## 3. 具体改了什么（全部为注释 / 分区）

1. **文件头重写**
   - 功能一览（电机 / 遥控 / 模式 / 避障 / 录制回放）
   - 六章代码目录与建议阅读顺序（`main()` → `av_gate()` → `motor_set_core()` → 录制回放）
   - 遥控键值表、引脚表、7 条"修改前必读"硬约束
   - 历史改动指向 `docs\正式固件开发记录.md` 附录 R

2. **新增 6 个章级分区 banner**
   - 第 1 章 硬件与参数（一~十一节）
   - 第 2 章 全局变量与索引（十二~十三节）
   - 第 3 章 中断与时基（十四~十六节）
   - 第 4 章 基础驱动（十七~二十二节）
   - 第 5 章 功能逻辑（二十三~四十三节）
   - 第 6 章 初始化与主循环（四十四~四十五节）
   - 原有"一~四十五节"编号保留，避免破坏 `docs` 与构建脚本中的节号引用。

3. **删除 / 迁移 C17~C25 历史修复记录**
   - 源码内的 ★Cxx / Cxx 变更标记从 46 处降到 0 处（仅文件头保留两行索引指引）。
   - 迁出内容汇总为 `docs\正式固件开发记录.md` 附录 R，并保留当前避障口径表。
   - 参数定义处只保留"当前值 + 物理含义 + 改动约束"，不再写"原来怎样、上机反馈怎样"。

4. **重写容易误导的注释**
   - `ir_det()` / `init_all()`：原文还写着"上电读一次 P3.7 自校准"，但 C22 起默认
     `IR_INV_FORCE=0`，自校准已不用；改为"默认低有效，只有设为 2 才自校准"。
   - `av_gate()`：补函数级说明，明确优先级顺序；把"为什么改"的长叙事压成
     "当前状态怎么流转"。
   - 避障参数区：门限顺序、量程上限与分档门限的区别、滞回方向各一句话说清。
   - 循迹段：删掉与参考工程逐条对照的历史，只留"压线/脱线怎么走"。
   - 车头红外机动段：保留时序、安全兜底、`avst`/`back_t0` 复用三件事。

5. **全局变量节增加"状态复用表"**
   - `av_clear_t`：锁存期间 = 开始退远时刻；避让期间 = 上次分档时刻。
   - `av_beep_n`：锁存期间 = 已响次数；机动期间 = 已做轮次。
   - `back_t0`：倒车限时起点；机动倒车/转弯段起点。
   - `samp`：录制采样基准；回放安全检测的测距节拍。
   - 这四项都是为省 RAM 的刻意复用（`-Ir` 变体只剩 1 B），本次只做说明，未拆分。

6. **补/改函数说明**
   - 新增：`av_gate()`、`mode_switch()`、`ms10_get()` 的简述。
   - 修正：`ir_det()`、`init_all()`、`av_mnv_start/step()`、`main()` 的步骤编号。

> 未改动：任何 `#define` 的数值、`sbit` 引脚、`#if` 结构、函数签名、变量类型、
> 执行语句顺序；未重命名任何符号；未拆分/新增 `.c` 文件。

## 4. 验证结果

### 4.1 编译

```text
powershell -NoProfile -ExecutionPolicy Bypass -File firmware\c51\build_c_abs.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File firmware\c51\build_c_abs.ps1 -Ir
powershell -NoProfile -ExecutionPolicy Bypass -File firmware\c51\build_c_abs.ps1 -Debug
```

三个变体均：

- C51：`0 WARNING(S), 0 ERROR(S)`（两遍编译都是）
- A51：`0 WARNING(S), 0 ERROR(S)`
- `c51_verify.py`：逐函数字节数一致，`BUILD OK`
- code 合计：**3,769 B**（C51 函数 3,740 B + 中断/入口/常量 29 B）

### 4.2 机器码逐字节比对（关键证据）

| 产物 | 整理前 SHA256 | 整理后 SHA256 | 结果 |
|---|---|---|---|
| `main.hex` | `AA147D3D…D386733` | `AA147D3D…D386733` | **完全相同** |
| `main_irdiag.hex` | `7CA52112…241B5F3` | `7CA52112…241B5F3` | **完全相同** |
| `main_dbg.hex` | `D420F9A8…841758` | `D420F9A8…841758` | **完全相同** |

完整值：

- `main.hex`：`AA147D3D8A3F92D7C954C1876156D28CCB84D001C37F6323C09ED8C81D386733`
- `main_irdiag.hex`：`7CA52112BC8E3B50435269DA5C501C88C07F1DC94D4B1CB7B33889BC3241B5F3`
- `main_dbg.hex`：`D420F9A8D305FAEE189E714C2343BD2823A9614385318EA4951D217AE5841758`

> 结论：本轮整理对机器码零影响。引脚、时序、PWM、中断、避障算法、录制回放
> 的行为均可认为与整理前一致；这是"功能一致"的强证据，不是口头保证。

补充校验：把 `/* */`、`//` 注释和所有空白去掉后，整理前后源码的 token 串
**完全相同**（29,114 个字符，`same_tokens=True`）。也就是说本轮没有改动任何
语句、宏值、`#if` 结构或函数签名，连一个字符的代码都没动。

## 6. 待确认的代码级整理（**未实施**，等确认）

以下项目会改动代码（哪怕只是删赋值），本轮一律未做。按风险从低到高排列：

| # | 项目 | 现状 | 建议 | 风险 | 影响 |
|---|---|---|---|---|---|
| 1 | `lastcmd` 只写不读 | 声明 L444；7 处赋值（L1163/2154/2503/2535/2603/2642/2809），无任何读取 | 删除变量、`LASTCMD_NONE` 及相关赋值 | 低 | 省 1 B DATA + 少量 code；需重编三变体并比对功能 |
| 2 | `playerr` 只写不读 | L472；赋值 L2512/2823，无读取 | 删除变量与赋值 | 低 | 省 bit 区与少量 code；回放行为不变 |
| 3 | `cur_act == 0` 可读性 | L1667/1689/1712/1719/2105 | 改成 `ACT_STOP`（两者数值相同） | 极低 | 机器码应完全不变；只是语义更清楚 |
| 4 | 编译期死分支 | `AV_L1=0` 的 `#else`（L1706~1715）、`AV_MNV_NEED_MOVING=1` 块（L1459~1465）、`IR_BEEP_SILENT=0` 块（L1391~1394） | 保留为回退开关，或删除死分支 | 低 | 删除后当前配置的 hex 不变，但失去回退路径 |
| 5 | 锁存分支里的重复判断 | L1608 `if (avoid_off()) return;`；L1586 已先把 `avst` 从 `AV_HOLD` 清掉，这一句永远不成立 | 删除这一句 | 低 | 省几字节；状态机行为不变 |
| 6 | `prox_beep()` 的 `MODE_PLAY` 判断 | L2224；主循环在 `MODE_PLAY` 时已 `play_step(); continue;`，不会走到这里 | 只保留 `MODE_TRACK` | 低 | 行为不变；少一个无效条件 |
| 7 | `av_gate_hold()` 的寻光分支 | L1408~1418 在 `AV_OFF_IN_LIGHT=1` 时不可达 | 用 `#if !AV_OFF_IN_LIGHT` 包住，或删除 | 低~中 | 行为不变，但涉及控制流程，需确认 |
| 8 | `AV_TURN_GEAR` 宏隐式依赖 `gear` | L239 | 改成局部变量或函数参数 | 中 | 动到机动转弯路径，不建议验收前做 |
| 9 | 重复的"停车 + 显示"序列 | `ir_brake` / `av_gate_hold` / `back_guard` / `rec_halt` 各写一遍 | 提取公共小函数 | 中~高 | 各处提示音/状态细节不同，易改出差异；不建议验收前做 |
| 10 | 拆分复用的状态变量 | `av_clear_t` / `av_beep_n` / `back_t0` / `samp` | 拆成独立变量 | 高 | `-Ir` 变体只剩 1 B，拆 2 B 变量直接编不过；不建议 |

**建议**：只做 #1~#3、#5~#6（真正无用或纯可读性）；#4/#7 可选；
#8~#10 验收前不做。任何一项实施前都应重编三变体、重新比对 hex，并单独记录。
