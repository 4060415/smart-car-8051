# 参考资料挖掘结果（引脚信息到底在哪、能读到什么）

结论先说：**引脚信息在资料里确实有，但"电机接哪几个口"这一条不是文字，是画线**。下面是逐份资料的实测结论。

### 原理图为什么"读不出文字" —— 这个结论已被推翻（2026-09-17 更正）

> ⚠️ **本节的旧结论是错的，保留原文只为记录教训。**
>
> 旧结论说"整份原理图没有任何字体对象，所有标号都是矢量轮廓（Altium 导出时勾了'文字转轮廓'）"。
> **真相**：字体字典藏在**压缩对象流**（`/Type/ObjStm`，该 PDF 的对象 1/3/4/5/13）里。
> 当时是直接对**原始字节** grep `/Font`，压缩流里的内容当然搜不到 —— 于是得出了错误结论。
>
> 实测：页面 `/Contents` = 对象 **14~21**，里面有**真文字操作符**：
>
> ```
> BT /TT2 1 Tf 0 4.4119 -4.4102 0 587.1 94.1306 Tm 0 Tc 0 Tw (C13)Tj ET
> BT ... Tm -.026 Tc (Z2)Tj T* -.0104 Tc [(11.)-18.8(05)13.6(92M)]TJ ET
> BT ... Tm .297 g -.0286 Tc (GND)Tj ET
> ```
>
> **所以标号是"文字 + 坐标"，导线是精确线段，两者都能直接抽出来，根本不需要 OCR。**
> 结论与完整引脚表见 `docs\引脚表_原理图追线.md`；工具见 `tools\pdf_vector.py`、`tools\schem_net.py`、`tools\pinmap.py`。

旧原文（已废）：

> 实测该 PDF 的内部结构：
> `/Font = 0  /BaseFont = 0  /ToUnicode = 0  /Type1 /TrueType /Type3 = 0`
> `/Subtype /Image = 0   BT（文本块）= 1 次   Tj/TJ = 各 2 次`
> 据此曾判断"全文件唯一的文字就是图框标题栏" —— **错**。

## 三、端口 ↔ 外设的具体连线：**已经从矢量数据追出来了**

原理图里 MCU 的 P0/P1/P2 到 L293D 的 `INPUT1~4` / 数码管 / 蜂鸣器之间是画线直连、没有网标，
OCR 确实读不到（OCR 只能读字，不能追线）。但**不必靠看图或实测猜**：

✅ **2026-09-17 已完成**：从 PDF 抽出的 **1753 条矢量线段 + 163 个结点圆点 + 341 个标号**，
用"共享端点 = 连接、交叉 = 不连接（除非有结点圆点）"的规则建网表，追出了引脚表。

**最关键的一条**：电机不在 P1，而在 **P0**：

| MCU | DIP40 | L293D |
|---|---|---|
| P0.0 / P0.1 / P0.2 / P0.3 | 39 / 38 / 37 / 36 | `INPUT1`(2) / `INPUT2`(7) / `INPUT3`(10) / `INPUT4`(15) |
| P0.4 / P0.5 | 35 / 34 | `ENA`(1) / `ENB`(9) |
| P0.6 | 33 | 蜂鸣器（R2 1.5K → V1 S8550） |
| P0.7 | 32 | 只挂 10K 排阻上拉，无外设 |

旁证：P0.0~P0.7 **每一根**都挂着一个 10K 排阻的独立电阻（P0 是开漏口，驱动 L293D 必须上拉）——
这个结构本身就证明 P0 是当输出用的。

完整表（含数码管段选、红外、按键、循迹、以及**未闭环项**）见 **`docs\引脚表_原理图追线.md`**。

## 四、复现这套挖掘能力的工具（都在 `tools\`）

| 工具 | 作用 |
|---|---|
| `pdf_to_png.ps1` | 用 Windows 内置 PDF 渲染器（WinRT `Windows.Data.Pdf`）把矢量 PDF 渲染成 PNG，**不需要 Ghostscript/poppler** |
| `ocr_images.ps1` | 用 Windows 内置 OCR（`Windows.Media.Ocr`，本机可用 `en-US` / `zh-Hans-CN`）把图片转文字，自动缩放超限图片 |
| `ocr_words.ps1` | 同上，但**输出每个词的 bounding box 坐标**（TSV），并支持裁剪+放大后重新 OCR —— 用来从图里还原版面（键值表就是这么还原的） |
| `extract_ppt_media.py` | 导出 PPT 里全部图片 + 生成"第几页幻灯片用了哪张图"对照表 |
| `extract_office_text.py` | 抽 pptx/docx 文字层 |
| `extract_pdf_text.py` | 抽 PDF 文字层（本例证明原理图没有文字层） |

实物资料与 PPT 的图片资产：`refs\`（113 张 / 26 MB）、OCR 文本：`refs\_ocr\`、`refs\_ocr_hw\`、`refs\_ocr_pdf\`。
