## 四、规矩（这个工作区**没有版本控制**，改坏了没法回退）

1. `原始资料\` 是只读参考区，不要在里面改东西（要改报告请另存副本到别处）。
2. 报告 `.docx` / `.pdf` 多为**独苗**，动之前先另存副本。
3. 写 `.ps1` 脚本必须**纯 ASCII**：Windows PowerShell 会把无 BOM 的 UTF-8 当 GBK 读，中文注释会乱码甚至报错。`.md` 不受影响。
4. 遥控键值有**四个副本**，改一处要一起改：`firmware\remote\remote.asm`、`firmware\car\config.h`、`firmware\car\car_asm.asm`、`firmware\c51\main.c`（第 4 个是 C 版）。
5. **撰写只动 `docs\` 与报告文件**。`firmware\`（代码固件）和 `tools\`（脚本工具）由 DSH 管，需要改动先说一声。
6. `docs\figs\*.geo.json`、`tools\_flow_spec\*.json` 是图表重建用的数据文件，**别删**。
