## 三、Keil 是 Eval 版：限额 2048 字节 —— ✅ 经实测**不阻塞**（不用先注册）

编译时链接器会打印：

```
* RESTRICTED VERSION WITH 0800H BYTE CODE SIZE LIMIT; USED: 0066H BYTE ( 4%) *
```

官方原文（[keil.com/limits](https://www2.keil.com/limits)）：C51 评估版**限 2 KB 目标码**，
"Programs that generate more than 2 Kbytes of object code will not compile, assemble, or link"。
注意两条：**只算 code、不算 data**（所以 240 B 动作缓冲放 RAM，不占额度）；
**卡点在 BL51 链接器**（汇编/编译阶段不拦，是链接时才报错）。

**结论：正式固件装得下，不用先注册。**
逐标号实测账单（`remote.asm` 的 1147 B 里，光串口调试就占 368 B ≈ 三分之一）
+ 正式固件预算（预估 **713~938 B**，占上限 35%~46%）见 **`docs\代码体积预算.md`**。
做法：写一块、跑一次 `build.ps1`、看 `code=` 数字。

**如果哪天真超了**，按这个顺序选（都不需要注册机）：

| 备选 | 说明 |
|---|---|
| 先砍调试打印 | `config.h` 的 `DEBUG_UART 0`，一键省约 368 B |
| 换免费无限制的汇编器 | **ASEM-51**（Intel 语法、直接出 Intel HEX、无 BL51 也就没有 2 KB 限额）—— 现有 A51 源码能否直接吃下去需实测 |
| 换 SDCC | GPL，mcs51 后端，**无任何体积限制**；汇编器是 sdas8051（语法与 A51 不同，要移植），`packihx` 转 `.hex` 后 STC-ISP 可烧 |
